# 公開画面の説明整理（Issue #19）

## 目的

画面に常時表示していた開発・運用向け説明を整理し、プロジェクト管理の操作に必要な情報を表示する。

## 受け入れ条件

- 接続モードの画面から「非商用」「架空データのみ」「DB接続モード」「6画面すべてDB接続済み」を外す。
- 実ユーザーと誤認しやすい固定のユーザー名を外し、アカウント画面へのリンクを置く。
- プレビュー環境の保存・ログイン不可という機能上の制約は引き続き表示する。
- 作成/編集ダイアログは入力項目と変更・削除の確認を説明する。
- メタデータ、README、GitHub説明文、SVGの共通説明を同期する。
- データ・認証・RLS・PreviewのDB分離は変更しない。開発時のデータ方針やホスティングの利用条件は開発・運用資料に残す。

## 検証

lint・型チェック・ビルド、接続モードの認証/操作E2E、Preview E2E、公開後の表示確認を実施する。
