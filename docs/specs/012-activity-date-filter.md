# 操作履歴の期間検索

## 目的・範囲

基本画面仕様にある期間検索を接続モードの操作履歴へ追加する。既存の操作・対象・操作者・プロジェクト条件と組み合わせて、日単位で記録を探せるようにする。

## 受け入れ条件

- GET `/api/v1/workspaces/:wid/activity` と `/activity` に `from` / `to` を追加する。YYYY-MM-DD形式の実在する日付（0001〜9999年）だけを許可する。未指定・空文字は制限なし。片側指定も許可する。
- 両端を日本時間の暦日として含む。fromは当日00:00以上、toは翌日00:00未満をUTCに変換して比較する。ミリ秒未満の記録も終了日から漏らさない。
- from > to、不正形式、存在しない日付、重複キーは400。UIは既存の検索条件エラーとリセット導線を利用する。
- ラベル付きの開始日・終了日を表示し、日本時間・両端を含むことを説明する。360pxで画面幅内に収まる。
- 絞り込み、操作者/プロジェクト条件の追加解除、ページ送りは期間を保持する。条件送信時にカーソルを解除する。所属先切替・リセットは期間も解除する。
- 既存のRLS、全ロールの閲覧権限、no-store、読取専用を維持する。テーブル・ER・監査トリガーに変更はない。

## 検証

認証E2EでJST午前0時の直前・一致、終了翌日午前0時の直前（マイクロ秒）・一致をfixture化する。片側指定、うるう日、不正日付、逆転、同時刻のページ送り、条件保持、リセット、モバイル幅を確認する。

## 対象外

時刻単位の指定、タイムゾーン切替、エクスポート、固定プレビューのデータ検索。
