# 本番の詳細ブラウザ性能計測（Issue #27）

## 目的

API応答時間と区別して、本番アプリの描画・操作・安定性を確認する。

## 条件と範囲

- Chrome DevTools公式CLI 1.12.0、独立した一時プロファイルを使用。使用統計とCrUX照会は無効。
- PCは1280×800 / CPU 1x / 回線制限なし。モバイル相当は360×800 / DPR 2 / CPU 4x / Fast 4G。実端末ではなくエミュレーション。
- ログイン画面と代表的なダッシュボードは各条件3回、その他主要画面は各条件の読み込みを確認。必要な場合のみ再測定。
- navigation traceはHTTPキャッシュを無視した再読込。サーバーのコールドスタートや実ネットワークの揺れは統制しない。
- LCP/FCP/CLS/TTFBを記録。操作を行う別トレースでINPを測定し、無操作トレースの未計測を0として扱わない。
- 主要リクエストとコンソールを確認。0msの改善見込みを根拠にコードを変更しない。
- 本番では既存のサンプルだけを閲覧し、メニュー/ダイアログの開閉など保存を伴わない操作を使う。
- パスワードは所有者がChromeへ入力。生トレース・認証情報はリポジトリへ含めず、集計値と制約だけを記録する。

## 完了条件

計測対象と条件、結果、問題の有無、改善の必要性を公開資料へ記録する。実ユーザーp75や高負荷時性能を保証するものではない。
