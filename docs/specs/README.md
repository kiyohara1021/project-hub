## 過去の仕様を読むとき

仕様には、その段階で実装しなかった機能を「対象外」として記載しています。これはアプリ全体の未対応一覧ではありません。例えば007で対象外だった担当件数と所属追加は、013・014で対応済みです。

現在の対応状況は[対応状況と今後の範囲](../roadmap.md)へ集約しています。新しい機能を追加するときは、既存の受け入れ条件を参照し、変更する条件と互換性を新しい仕様に記載してください。
