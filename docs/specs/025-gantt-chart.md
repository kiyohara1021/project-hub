# ガントチャートとタスクの開始日

Issue: [#77](https://github.com/kiyohara1021/project-hub/issues/77)

## 目的・範囲

プロジェクトのタスクを開始日から期限までの期間で比較する。開始日を任意項目として追加し、カンバンの作成・編集で設定する。ガント上でのドラッグ編集、依存関係、自動日程調整は対象外。

## 契約

- `tasks.start_date`は任意の日付。開始日・期限は0001-01-01〜9999-12-31とし、両方設定されたときは開始日が期限以前でなければならない。APIとDBの両方で検査する。
- 作成APIの開始日省略は未設定として扱う。編集APIで省略した場合は保存済み開始日を維持する。既存RPCの呼び出しと再送記録は互換性を保つ。開始日の変更もversionによる競合検査・操作履歴を維持する。
- `/projects/:id/gantt?workspace=:wid`で表示する。接続モードは既存のプロジェクトアクセス検査とユーザーJWT/RLSを使用する。閲覧者・アーカイブ済みプロジェクトも閲覧できる。無所属・別プロジェクトは既存どおり404、未認証はログインへ誘導する。
- 表示単位は日（14日）と週（12週）。開始日、表示単位、ページ送りをURLに保存する。前後の期間へ移動できる。日付は日本時間の今日を基準とし、日付計算はUTC上の日単位で行う。
- タスクはID順で1ページ25件、継続キーで次のページへ移動する。期間を外れたタスクは「表示期間外」、片方または両方の日付がないタスクは設定済みの日付と「期間未設定」を表示する。ページをまたぐタスクを取得済みとして扱わない。
- タスク名・状態・開始日・期限を表として提供し、棒だけに情報を依存させない。チャートはキーボードでスクロールできる領域とし、360pxでは領域内だけが横にスクロールする。
- 画面デモでも同じチャート表示を用意し、編集は行わない。カンバンと課題からガントへ移動できる。

## 受け入れ条件

- DBテストで開始日の保存・明示解除・旧RPC呼び出しでの保持、逆転日付拒否、再送本文の不一致、権限・アーカイブ・version競合を確認する。
- 認証E2Eで開始日入力→ガント表示、日/週切替、期間移動、片側未設定・期間外・ページ送り、360px内スクロールを確認する。
- 画面デモE2Eでガントへのリンクと日/週表示を確認する。既存カンバンとCSPのテストも回帰確認する。
