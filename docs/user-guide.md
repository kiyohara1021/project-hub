# 利用ガイド

登録済みアカウントで[ProjectHub](https://project-hub-zeta-nine.vercel.app)にログインして利用します。管理者・メンバー・閲覧者で操作できる範囲が異なります。詳しい権限は[基本仕様](specification.md#機能と権限)を参照してください。

## ログインとワークスペース

ログインすると「ログイン状況」に所属先が表示されます。共通メニューから各画面へ移動してください。複数のワークスペースに所属する場合は、各一覧の選択欄で切り替えます。

ログイン状況には自分のユーザーIDも表示されます。ワークスペースへの所属追加を依頼するときは、このIDを管理者へ伝えてください。

ログインできない場合は、入力内容と接続状況を確認してください。アプリからのユーザー登録・招待メール・パスワード再発行は提供していません。アカウントの準備は管理者が行います。

### 表示名を変更する

「ログイン状況」の「表示名」を入力し、「表示名を保存」を選んでください。前後の空白を除いて1〜80文字です。閲覧者や所属先のないユーザーも、自分の表示名を変更できます。ほかの人の表示名は変更できません。

変更後は、メンバー一覧や担当者候補を開き直すと新しい表示名が表示されます。今後の操作履歴には新しい名前が記録されます。過去の操作履歴とコメントの投稿者名は、記録したときの名前のまま残ります。通信に失敗した場合は、入力した名前を確認して同じ内容で再試行できます。

## ダッシュボード

進行中のプロジェクト数、完了率、期限超過タスク、未解決課題を確認できます。「最新の状況を取得」で更新してください。

プロジェクト進捗、自分の未完了タスク、最近の操作も表示します。各リンクから関連するプロジェクトや一覧を開けます。

## プロジェクト

プロジェクト一覧では名前と状態で検索し、名前を選ぶとカンバンへ進みます。管理者はプロジェクトを作成・編集できます。

終了したプロジェクトはアーカイブしてください。アーカイブ内のタスク・課題は閲覧のみになります。再び編集する場合は、管理者がプロジェクトの状態を戻します。

## カンバン

タスクを「未着手」「進行中」「レビュー」「完了」の列で管理します。メンバーと管理者は、タスクを追加・編集・削除できます。担当者・優先度で絞り込めます。

PCではドラッグ、キーボードやスマートフォンでは状態選択で移動します。列内の順序は「上へ」からも変更できます。スマートフォンでは状態を選んで1列ずつ表示します。「さらに読み込む」で続きのタスクを表示します。

## 課題

初期表示は未解決・調査中の課題です。件名・状態・優先度・担当者で絞り込めます。

管理者とメンバーは課題を作成・編集し、状態を変更できます。解決済みの課題を再開するときは、状態フィルターで対象を表示して編集してください。状態変更と削除には確認があります。

### 課題にコメントする

課題の「コメント」から調査経緯や対応内容を記録できます。新しいコメントから順に表示し、「さらに読み込む」で続きを表示します。本文はプレーンテキストです。

管理者とメンバーは投稿できます。編集・削除は管理者、または投稿者本人のメンバーが行えます。閲覧者とアーカイブ内では閲覧のみです。削除は内容を確認して実行します。編集で競合した場合は入力を確認して最新版を読み直してください。

## メンバー

所属者のロール、未完了タスク数、未解決課題数、参加日を確認できます。担当件数は、アーカイブ以外のプロジェクトが対象です。

管理者は次の操作ができます。

- 「メンバーを追加」：事前登録済みユーザーのIDとロールを指定し、内容を確認して所属を追加します。初期ロールは閲覧者です。
- 「権限を管理」：ロールの変更または所属解除を確認して実行します。

所属追加はアカウント作成とは別の操作です。対象のユーザーIDは事前に確認してください。最後の管理者を失う変更はできません。所属解除時は、その人のタスク・課題の担当が未割当になります。

## 操作履歴

対象種別・操作・開始日・終了日で絞り込みます。各記録のリンクから、操作者やプロジェクトの条件を追加できます。期間は日本時間で、開始日と終了日の両方を含みます。片側を空欄にすると、その側の期間を制限しません。

ページを送っても検索条件は保持されます。「リセット」で条件を解除します。履歴は読み取り専用で、本文などの詳細値は表示しません。

## 保存できないとき

入力エラーは項目やダイアログ内のメッセージを確認してください。編集ダイアログで他の操作と競合した場合は、未保存の入力を確認したうえで「入力を破棄して最新版を読み直す」を選択します。カンバンの移動で競合した場合は「一覧を再読み込み」を使います。

作成中に通信が切れた場合、同じ内容で再試行できます。送信結果が不明なまま入力を変える前に、一覧も確認してください。画面の取得に失敗した場合は「再試行する」または再読み込みを使います。
