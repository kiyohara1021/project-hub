## 仕様と記録の読み方

上記の仕様・設計資料は、現在の実装を確認するための資料です。[機能別仕様](specs/README.md)には、実装時に決めた受け入れ条件と検証方法を残しています。各段階の「対象外」は、その時点の作業範囲を示します。後続の実装で対応した機能もあるため、現在の未対応項目は[対応状況](roadmap.md)で確認してください。

[公開履歴](history/deployment-2026-11.md)と[リポジトリ公開時の確認記録](publication-review.md)は、当時の実施内容を記録したものです。現時点の稼働状態や性能を継続的に保証するものではありません。
